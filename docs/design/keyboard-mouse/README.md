# 键盘小鼠角色设计

键盘小鼠住在键盘缝里，专门把代码里的 bug 拖回窝里。它胆小、嘴硬，
又会认真完成工作；被发现时总是假装自己只是路过。

## 固定识别点

- 暖燕麦棕毛色与奶油色口鼻、腹部
- 自身右耳（正面看位于画面左侧）的折角
- 缺了一小角的门牙
- 尾端带折线的细长尾巴
- 不穿固定服装；键帽和小 bug 只作为情境道具

## 版本

- `character-sheet-v1.png`：用户认可的原型版。偏儿童绘本和写实质感，
  保留作为角色性格、动作和故事基准，不被后续卡通化版本覆盖。
- `character-sheet-v2-cartoon.png`：在 V1 身份和六个动作不变的基础上，
  放大头部、缩短身体并简化毛发、爪子与道具细节的卡通版。
- `character-sheet-v2-cartoon-hero-small.png`：V2 主形象的小尺寸检查图。
- `production-states-v2.jpg`：最终接入桌宠的成长与动作素材总览。
- `animation-sources-v3/`：V3 逐帧动画源稿。V2 静态 PNG 继续保留为回退，
  V3 不覆盖用户已经认可的角色设定。

## 桌宠动作映射

生产素材位于 `src/renderer/pets/aetherling/`。待机使用当前成长形态；工作时
拖 bug，查看时露出怀疑表情，等待时把 bug 藏在背后，完成时站上键帽得意，
失败或被点击时受惊，安静陪伴时可以抱着键帽睡觉。

V3 使用透明 APNG：待机帧真正改变眼睛、胸口、耳尖和尾尖；工作帧改变手臂、
后脚、绳子张力和 bug 位置；完成与失败包含起势、失衡、落地和恢复。启用这些
逐帧素材时会关闭旧版的整图旋转、摇摆和拉伸，避免“贴纸左右晃”的感觉。

新增的语义动作继续使用同一套角色锚点：任务开始时托腮思考，等待确认时从
键帽后探头，主动投喂或低频陪伴时会吃一块 Bug 形饼干。思考可以循环，但
等待与进食各播放一次并停在自然收尾，后续状态到来时再切换，不制造连续噪声。

## V3 节奏与尺寸

- 自动陪伴第一次动作延后到 25–45 秒，之后每 55–110 秒才触发一次。
- 自动动作只保留安静说话、睡觉、偶尔庆祝和稀有进食，不再轮流触发摇摆、
  拉伸和跳跃；进食约每五轮低频陪伴才出现一次。
- 尺寸范围调整为 12%–75%，默认值为 42%；V5 用户的旧尺寸会按滑杆相对位置
  映射到新范围，而不是粗暴截断。
